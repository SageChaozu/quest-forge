Unsaved changes

Open your RPG Maker MZ project

Quest Forge reads the quests and pop-up messages out of js/plugins.js, lets you edit them in a real form instead of nested JSON boxes, and writes them back.

  1. 1Pick your project folder — the one containing js/, data/ and index.html.
  2. 2Edit quests, objectives, rewards and notifications. Pop-up messages are picked from a list, so a name can never be mistyped.
  3. 3Hit Save to project. A timestamped backup of plugins.js is written first.

Close RPG Maker MZ before saving. The editor writes js/plugins.js directly, and the editor overwrites that file when it saves the project.

Plugins & credits

Quest Forge is an unofficial editor. It doesn't contain any plugin code — it edits the settings of plugins written by Casper Gaming, whose Dev Corner is where you download them and read their documentation.
